# Provider等待中取消的阶段证据

HA-0091只加固取消测试，不改生产期限、SDK初始化配置、账本或运行时。

1. 测试使用真实DSH SDK和平台合成Provider，Run期限300秒；初始化不是被测取消阶段。独立75秒启动等待只作测试设置失败上限，不是新的生产SLO，不到达Provider必须失败。
2. Provider到达后保持挂起，不使用0.8秒延时模拟“仍在等待”。由测试明确执行取消，随后12秒内要求运行线程结束，挂起协程已收到取消。
3. 模型调用恰好一次，无实际usage则调用行保持unknown、spent为0、reserved大于0；预算根保持cancelled而非被改写成usage_unknown。没有产物、自有目录无残留。Run终态为cancelled，重复execute不能增加调用或发布。
4. 设置或断言失败也必须在finally释放合成等待、取消任务并回收测试线程，避免影响后续测试。只操作该测试临时库与自有目录。
5. 移除取消或取消监视的突变应在已经到达Provider的行为断言失败，不接受导入错误或启动失败作为取消保护证据。完整门禁失败日志保留，单例通过不能代替完整门禁。
6. 同文件的SIGKILL探针也必须先等到真实SDK第二次Provider调用，另确认会话正文确实落盘再kill；其20秒设置上限同样改为独立75秒，Run期限300秒。原有kill后5秒退出及recover清理断言不放宽，不把未抵达第二轮当作崩溃恢复证据。
