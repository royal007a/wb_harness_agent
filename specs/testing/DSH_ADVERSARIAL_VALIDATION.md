# HA-0078：DSH 补充验证

基线 c43df5b。只补测试和证据，不改生产行为或部署，不调用真实 Provider，不读取 Keychain。

## 验收矩阵

1. 真实官方 DSH + 合成 Provider：多轮搜索/读取、8/9 次模型请求、16/17 次工具执行、异常 usage、同 Run 并发 execute、独立 Run 内容隔离。
2. 平台编排（合成 Adapter，明确不算 SDK 证据）：取消后迟到结果、发布事务失败、队列并发上限、幂等并发、1001 条分页、请求边界和关门回放。
3. Provider 协议（HTTPX MockTransport，不算真实网络）：固定端点/模型/输出上限、无重试/重定向、编码和响应字节上限、非法工具与终止组合。
4. 工作目录（临时目录）：登记损坏、越界名称、符号链接与身份不一致时不删除；pending 后显式再次清理可成功。现有 SIGKILL 测试一并回归；不声称自动延迟重试已实现。
5. 选取单点突变验证新增测试能发现行为退化；不得把导入/语法失败当作杀死突变。

失败逐项断言错误码、调用次数、状态和产物；异步等待用事件/有界 join。所有进程和数据只属于测试。

## 非证据

不是语义质量、真实 Provider 稳定性、OS 沙箱、负载容量或部署验收。新发现的生产缺陷单独登记，不通过修改断言隐藏；本次不默默扩大为运行时重构。
