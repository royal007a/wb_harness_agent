# 百度网盘分享链接下载（官方客户端）

此 Skill 只处理本次用户消息或用户明确引用的消息里的分享链接；不要扫描无关聊天历史，也不要把链接、`pwd`、Cookie、token 或文件内容写入日志、计划、证据或回复。

1. 确认用户明确要求打开/下载这一个链接。若没有明确动作，先询问；若用户已经说“试试”“下载”或“打开”，可继续。只接受 `https://pan.baidu.com/s/...` 的链接，拒绝短链、重定向、非 HTTPS 和带 fragment 的地址。
2. 用标准输入把链接交给固定脚本，避免将含 `pwd` 的 URL 放进进程参数。脚本只启动本机 `/Applications/BaiduNetdisk_mac.app`，自身不发网络请求、不登录、不绕过提取码/验证码，也不自动选择下载位置：

   ```sh
   python scripts/baidu_share_handoff.py handoff --stdin <<'URL'
   <仅粘贴本次用户明确提供的分享链接>
   URL
   ```

   先用 `--dry-run` 可仅校验链接和本机客户端。stdout 只返回分享链接的 SHA-256 摘要，不返回原链接或提取码。
3. 明确告诉用户：需在官方客户端内自行登录、确认提取码、选择保存位置并点击下载。不要尝试自动化 GUI、复用浏览器会话或调用未核验的数据面 API。
4. 用户确认下载完成后，请其提供一个明确文件路径；只能校验 `~/Downloads` 下的常规、非符号链接文件，脚本不读取文件内容：

   ```sh
   python scripts/baidu_share_handoff.py claim --file ~/Downloads/<文件名>
   ```

5. 成功后仅把已校验的本地路径交给后续已授权的阅读任务。文件移动、重命名、内容解析、上传或删除都需要该任务自己的授权与安全边界。

该 Skill 是官方客户端交接，不是百度网盘数据面连接器。目录列举、脚本直链下载、分享链接导入和文档解析仍受项目 `TD-020` 的独立设计、最小权限、删除和审计验收门禁约束。
