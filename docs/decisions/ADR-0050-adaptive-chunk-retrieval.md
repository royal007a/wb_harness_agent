# ADR-0050：父子 Chunk 与 Slot 驱动的动态检索（本地确定性切片）

## 状态

Proposed（本地受限实现）

## 决策

采用结构边界优先的父子文档编译、加权 RRF 候选融合和 Slot/Gap 驱动的最小充分停止。实现只运行本地确定性 keyword/temporal/graph 路径，所有预算沿用 retrieval-state@2，semantic/api/外部源保持未准入。

## 原因与边界

固定长度会在召回精度与上下文完整性之间失衡。父 Chunk 提供上下文，子 Chunk 提供精确证据；结构边界和硬上限共同防止切断条款。路权只影响已准入候选排序，不改变权限、预算或事实权威性。Slot 完成度是效果停止条件，预算耗尽是硬停止条件，两者不互相放宽。

## 后果

每个子证据可追溯到父上下文和源码哈希，评测可以定位到入库/召回/排序/停止阶段；但当前不声称具备 embedding、reranker、外部检索或 Agentic RAG 运行时能力。
