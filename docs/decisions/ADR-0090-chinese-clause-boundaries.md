# ADR-0090 中文条号与原文偏移

状态：Proposed，待独立复审及完整门禁。

复审发现共用HEADING仅识别阿拉伯数字“第N条”，12条普通中文条号会聚成一块。DSH复用此切块器，未单独解决这个问题。

采用最小的行首中文数字字符集合，保持原文及现有硬长度限制。不转换数字、不把块ID冒充法律条号，不增加模型调用或用标注引导检索。兼容边界和反例见CHINESE_CLAUSE_BOUNDARIES.md。

缩进原文的section_start必须指向实际行起点；flush统一计算前导空白。否则重复偏移会让合法缩进文本报原文切片不一致。该修复与新增中文标题的偏移验收同属本切片。

旧历史不重写；新中文输入的块ID可能改变，评测另存。未实现算法版本持久绑定或证据续跑。

复审阶段确认下游词表原来要求付款词和例外词同块。48d32c7曾扩大为全文共现，被复审拒绝且long-01评测退化：独立争议解决被误列为付款例外。撤回全文方案；最终采用实际parent_id和structural_path限定跨子块关联。单纯相邻也不足够，因为争议解决恰好紧邻付款例外。

元数据由平台本Run的切块结果构建，计划和提交校验共同使用。不退回错误大块，不猜测独立条款的语义；缺元数据时只做原同块匹配。仍可能漏掉跨独立条款的隐含关联，该边界交由人工核对，不自动补出结论。
