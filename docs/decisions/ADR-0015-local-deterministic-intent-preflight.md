# ADR-0015：本地确定性意图预检

- 状态：Accepted（HA-0013 受限实现）
- 日期：2026-09-13
- 触发：用户授权实现 Intent Contract、槽位 Schema、缺槽澄清、规则路由/拒识及评测集。

## 决策

先实现不依赖模型的本地预检 API。它只支持已批准的 CSV 固定分析场景，输出版本化 `intent-contract@1`；路由是对显式本地分析引擎的建议，且只能由用户后续显式提交创建 Task。输入不写入预检状态，响应不回显目标正文。

规则只识别“分析动作 + 数据语义或已选择 CSV”。资源缺失时提出固定澄清；不支持或不确定时明确 `rejected`。预检返回规则 ID、槽位、硬约束、路由版本及确定性置信度来源，并由固定评测夹具回归。

## 后果

- 工作台得到可观察的自然语言入口，却不会因低质量模型输出触发执行或隐式换引擎。
- 规则覆盖面有限；不支持的意图必须被拒绝，不能以关键词猜测扩展到研究、网盘或其他路线图能力。
- 将来接入模型或向量检索必须建立独立评测/隐私/阈值/回滚决策，不能替换规则而不留版本记录。
