# ADR-0007：模型生成代码必须进入远程隔离沙箱

- 状态：Proposed
- 日期：2026-09-08

## 背景

CodeAct 会执行模型生成代码。进程内解释器、AST 过滤或包白名单能减少误用，却不能构成针对不可信代码的安全边界。

## 决策

建议真实 CodeAct Run 使用一次性远程沙箱或等价强隔离执行环境。输入只读挂载、输出单独可写，默认禁网，限制 CPU、内存、磁盘、进程和时间，不注入长期凭证，并在结束后销毁。宿主本地执行仅限固定的可信测试代码。

## 后果

- 需要选择沙箱实现并验证逃逸、清理、取消和成本。
- 沙箱故障必须映射为稳定平台错误，不能由适配器伪装为任务成功。
- P0 实现前必须先完成安全探针与威胁模型评审。
