# ADR-0008：图片理解显式路由到 Doubao-Seed-2.1-Turbo

- 状态：Proposed（用户已指定，待能力探针）
- 日期：2026-09-08

## 背景

用户指定图片类任务使用 `doubao-seed-2.1-turbo`。图片输入理解与图片生成是不同能力，公开产品页不足以证明当前账户端点的完整图片输入约束。

## 决策

建议将 OCR、截图理解和图表解读的逻辑路由固定为 `doubao-seed-2.1-turbo`，禁止静默回退。启用前用账户内实际 endpoint 完成格式、尺寸、多图、OCR、图表、结构化输出、费用、地域和错误语义探针。图片生成/编辑保持独立未决路由。

## 后果

- Run 会记录实际部署 ID、探针版本和是否使用图片输入。
- 能力不匹配时返回 `MODEL_CAPABILITY_MISMATCH`。
- 关键数字仍从源数据确定性回算，视觉模型结果只作为分析信号。
