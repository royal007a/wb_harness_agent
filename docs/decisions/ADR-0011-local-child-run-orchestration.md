# ADR-0011：有界 Child Run 编排切片

状态：Accepted（2026-09-12 用户 /goal 一小时实现授权，限本地演示）。

P0 原有离线分析边界不变。本切片是 P1 准备工作，不以模型配置缺失为由停止所有可独立验证工作，也不将确定性执行器冒充 Claude SubAgent。

- 公司 × 专项形成最多 9 个 Child Run，深度固定为 1，全局最多 3 个子任务同时执行。
- 复用 tasks/runs/events/artifacts，无第二套终态枚举；每个 Child Run 有 parent_run_id/parent_step_id，继承同一 Task 和 trace。
- Task 保存不可变分配清单与资源引用；执行器只接收该子任务的窄上下文，不接收数据库、兄弟输入或父对话。这是应用数据分发边界，不是同进程线程的安全沙箱。
- root Run 预留总步骤预算，子任务均分可消费预算，费用为零且真实模型禁用。子权限只能收窄；超出配额在创建前拒绝。
- partial failure 策略明确为 fail_parent 或 continue_with_warning。后者只在有至少一个成功结果时产出带缺口的报告；未知风险不可写为无风险。
- 取消父 Run 级联终止所有非终态子 Run，保留已提交结果；取消一个子 Run 由父策略汇总。停止/超时在固定函数的检查点退出，线程不是不可信代码执行器。
- 重启后正在运行的树明确失败并关闭孤立子任务；从未启动的根任务可重新领取。重跑创建新的整棵 Run 树，不修改旧证据。
- 仅使用自建 synthetic 数据，不下载用户未提供的 PDF、不安装未审查 ClawHub Skills、不调用未批准模型或联网搜索。

原生 Claude AgentDefinition 未来映射到同一角色/资源/预算契约，需要固定 SDK 与端点实测，不让 SDK 内部状态成为平台事实源。主 Agent 是否主动调用或并行不能取代平台必须执行的扇出清单。
