# ADR-0092：清理失败与主错误分离

状态：待复审；仅DSH本地适配器。

第五轮完整验证在 killpg(SIGTERM) 的 PermissionError 上失败。堆栈明确显示它覆盖了协议错误，后面的网关和租约释放没有执行。操作系统为何返回EPERM尚未确定；不归因于机器负载，也不声称是PID复用。另一个初始化错误被改写的失败仍需单独确认。

决定：逐阶段收集清理错误但不记录其原文。存在主异常时保留它；正常返回路径遇到任何捕获的清理故障时，以固定 DSH_CLEANUP_FAILED 失败，不发布结果。信号被拒后不继续升级信号，仍有界等待已创建的子进程。管道、网关、线程join和本进程工作目录租约分别尝试释放。

工作目录不直接rmtree，继续使用既有登记和活进程检查。权限未知或进程仍活着时为pending，后续既有恢复清理再处理。因此本改动不承诺清理失败时正文立即消失，不保证进程一定被终止；不新增权限、不杀恢复出来的PID。未知用量账本保持原规则。

非目标：解决操作系统信号权限、PID/PGID复用、任意应用编程错误、网关线程整体超时或系统级沙箱。测试只用本地Python子进程和mock信号，不能代替真实SDK及部署验证。
