审查将同时检查真实状态转换，而不是只补Schema。遵循CORE_CONTRACTS终态不可变：
Gate当前状态检查移入首次决策事务；合法幂等回放只返回历史收据。

事件游标按实际返回页推进；详情独立读取最新Gate事件，不复用500条默认第一页。

使用临时SQLite和合成Adapter验证，既有真实Faux sidecar另测。
