# ADR-0064：幂等性不缓存授权

状态：0ee58a0已独立Approved，实际部署待完成；基线116a164。

ADR-0035的当前资格承诺与先返回幂等缓存的实现冲突。Session归档后旧key成功，
说明“没有第二次副作用”不能代替“现在可以读到旧响应”。

采用必填的只读replay_authorize回调：在原事务、相同digest命中后核对当前资格，
通过才回放历史收据；未命中沿用原完整业务动作。各模块显式登记授权映射，共用
Foundation的事务/幂等算法，不依赖scope字符串猜测业务，也不执行action作权限探针。

回放不重做状态/CAS/lease/freshness，因为首次成功通常已经改变它们。当前权限、
scope/owner与可执行状态分离；失去前者就拒绝，只有后者变化仍可读取历史收据。
可从收据比对的授权scope重绑拒绝，不用新位置的权限释放旧位置内容；旧收据未保存
的上游关系不在此保证中，详见规格。既有成功HTTP码与body不变，
失权旧key从成功变现有拒绝码是刻意兼容变化。没有真实身份或外部副作用扩展。

逐入口合同、边界和验证：specs/testing/TEAM_REPLAY_AUTHORIZATION.md。
