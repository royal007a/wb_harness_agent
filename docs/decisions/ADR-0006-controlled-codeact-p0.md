# ADR-0006：以受控 CodeAct 数据分析作为 P0

- 状态：Proposed
- 日期：2026-09-08

## 背景

通用 Agent 平台范围过大，无法用一个可验收场景验证核心契约。三份参考材料表明，数据分析能体现 CodeAct 在组合计算、变量传递和动态流程上的优势，同时也暴露生成代码、产物和可复现性边界。

## 决策

建议把“单个已登记 CSV → 受控代码分析 → Markdown 报告、图表与清单”作为 P0。先用 Mock 适配器验证 Task/Run、事件和错误语义，再用 Smolagents CodeAgent 做首个候选真实适配器。P0 禁止网络、外部写入、动态依赖安装、多 Agent 和任意 MCP。

## 后果

- 能以一个窄场景贯穿契约、安全、产物、评测和运维。
- Smolagents 是待探针和评审的候选，不是已完成选型。
- 外部检索、多 Agent 和其他框架延后到基线证明确有收益后。
