# ADR-0001：Harness 只作为结构模板

- 状态：Accepted
- 日期：2026-09-08

## 背景

长周期 Agent 研发需要跨会话保留项目知识、任务状态、授权边界和验证证据，但这些治理文件容易被误解为产品运行时的一部分。

## 决策

使用 `AGENTS.md`、`docs/`、`exec-plans/`、`harness/` 和 Evidence 构成研发治理 Harness。它只定义人机协作制度和机器任务状态，不进入生产请求链路，不作为新的 Agent 引擎。

## 后果

- 规格、任务、计划和证据的职责清晰，可跨会话恢复。
- 产品代码不能依赖 `harness/tasks.json` 作为线上任务库。
- 未来可实现辅助脚本，但脚本只能维护研发状态，不能混入业务运行逻辑。
