# ADR-0016：模型化意图路由先经脱敏离线评测与影子门禁

- 状态：Proposed
- 日期：2026-09-13
- 触发：用户选择启动模型化意图评测准备，但尚未提供获准模型连接配置。

## 背景

`rules@1` 仅服务本地 CSV 分析，故意拒绝大部分开放表达。直接把模型接到预检会带来错误路由、提示注入、生产文本外发和难以回滚的风险；固定 7 条规则样例也不足以作为模型准入依据。

## 决策

先建立独立于运行时的 `intent-evaluation@2`：只允许手写、合成、已去标识的夹具，明确覆盖支持、澄清、范围外和安全边界四类表达。候选模型必须在外部获准运行器中以 `shadow` 模式提交无原文结构化预测，且由本地评分器验证 fixture 摘要、预测一一对应、覆盖、指标与策略阈值。

任何通过该策略的候选只获得“可以讨论影子回放”的资格，不获得 API 路由、Task 创建、引擎选择或权限。真实模型调用仍需要单独的端点/模型/凭证引用/预算/数据范围批准，并维持 `rules@1` 与显式提交作为回退。

## 后果

- 评测与生产数据、模型凭证和用户执行链解耦，可复现且可审计。
- 扩展语义覆盖会显式暴露规则基线不足，而不是把规则分数误报为模型质量。
- 需要维护合成语料和阈值；阈值校准、真实影子数据治理和用户可见模型路由另行立项。
