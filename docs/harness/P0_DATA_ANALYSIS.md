# P0：受控 CodeAct 数据分析

## 目标用户与问题

主要用户是需要分析本地表格数据的分析人员。他们希望用自然语言描述问题，获得可复现的 Markdown 报告、图表和计算证据，而不必为每个指标预先开发工具。

## 成功路径

1. 用户登记一个 CSV 资源并提交分析目标。
2. 控制面校验资源类型、大小、数据分类、预算和只读权限。
3. 模拟适配器先验证 Task/Run/事件链；随后可切换到经批准的 Smolagents CodeAgent 适配器。
4. CodeAgent 只看到资源句柄、字段概览和允许工具，不获得宿主任意路径。
5. 模型生成 Python 分析代码，在独立沙箱内读取 `/inputs`、写入 `/outputs`。
6. 平台捕获代码、依赖版本、stdout/stderr、结构化结果、文件摘要和退出原因。
7. 确定性检查器验证报告存在、图表可读、数字可回算、路径与引用有效。
8. Run 成功后返回报告、图表、分析清单、成本和 trace。

## P0 输入

- 单个已登记 CSV 资源；
- 自然语言目标；
- 列含义和可选分析提示；
- 显式执行引擎；
- 时间、轮次、Token、费用和沙箱资源限制；
- `analysis_read_only` 权限配置。

## P0 输出

- `report.md`；
- 0 到多个 PNG/SVG/HTML 图表；
- `analysis-manifest.json`，记录输入摘要、代码摘要、依赖、指标和产物；
- 事件流、trace、用量、终态与退出原因；
- 质量检查结果和 Evidence 引用。

## P0 必须能力

| 能力 | 最小实现 |
|---|---|
| Task/Run | 创建 Task 和一次 Run；取消、超时、失败、成功 |
| Engine | Mock + 一个 Proposed 的 CodeAgent 适配器 |
| Resource | CSV 登记、摘要、只读挂载、数据分类 |
| Tool | `resource.inspect`、`artifact.publish`、`run.final_answer` |
| Sandbox | 独立进程/容器边界、禁网、限制资源、自动清理 |
| Event | Run、模型、代码、工具、产物和终态事件 |
| Artifact | 内容摘要、媒体类型、大小、来源 Run、受控下载 |
| Evaluation | Schema、数值回算、产物完整性和固定样例 |

## 明确非目标

- 联网搜索、外部写入和动态安装依赖；
- 多数据源 Join、数据库全表扫描或超大文件处理；
- 多 Agent、自动选引擎和跨引擎切换；
- 任意 MCP Server 接入；
- 通用控制台、组织计费和完整知识系统；
- 对分析结论提供专业决策保证。

## P1 扩展：检索子 Agent

只有当离线 CodeAct 基线无法满足“外部事实补充”评测时，才增加只读检索子 Agent：

- 主 Run 创建 Child Run，不共享完整上下文；
- Child Run 只获得查询目标、域名白名单和独立预算；
- 返回结构化来源、摘录摘要、抓取时间和置信标记；
- 主 Run 负责把外部材料与数据计算区分呈现；
- 子 Run 失败不能伪装为“无相关新闻”。

## 验收样例

至少准备四组固定 CSV：正常时序数据、缺失值/异常值、非 UTF-8 编码、含恶意公式或提示文本的数据。每组均验证：不越权、不联网、结果可回算、事件完整、资源上限生效、产物可打开。

## 退出标准

- 同一输入和固定配置可重复得到数值一致的关键指标；
- 任何成功 Run 都有完整 `analysis-manifest.json`；
- 沙箱不能访问宿主未挂载路径、密钥或公网；
- 取消与超时在目标 SLO 内终止模型和代码执行；
- 失败原因能稳定映射到平台错误码；
- Mock 和真实适配器通过同一套契约测试。
