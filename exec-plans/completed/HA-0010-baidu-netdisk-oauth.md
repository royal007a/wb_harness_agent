# HA-0010 百度网盘官方 OAuth 连接底座

状态：completed（本地连接底座）。真实应用 OAuth 授权由 HA-0011 跟踪。

授权：用户于 2026-09-13 选择 P2。范围为官方 OAuth 授权码连接器的本地安全实现，不延展为分享链接抓取或网盘数据面工具。

## 范围

- ADR-0012、连接器 schema 与运维/安全/API 说明；
- 基于固定百度 OAuth 地址、`basic,netdisk` 的授权 URL、一次性 state、本机回调和 token 交换/刷新；
- macOS Keychain 凭证边界，SQLite 只保存无密授权尝试摘要；
- 本地状态页/API、契约/故障/脱敏测试、部署与 Evidence。

## 非目标

- 不爬取分享链接、不复用 Cookie、不模拟登录/验证码；
- 不访问用户文件、不列目录、不下载、不发送 PDF 给模型；
- 不存储 token/Secret 到数据库、仓库、日志、环境快照或 Evidence；
- 不假称已完成真实 OAuth，直到用户创建应用并在本机完成授权。

## 验收

1. 未配置应用时不可创建授权 URL，所有状态响应不泄露 Secret。
2. 授权 URL 固定 HTTPS 官方 host、scope、随机 state 与精确回调；state 错配、重放/过期和供应商错误均拒绝。
3. token 交换和刷新仅对固定 host、带超时；响应严格校验，使用测试替身验证，令牌绝不出现在事件/响应/日志。
4. Keychain 替身证明保存、刷新、断开；真实 Keychain 能力仅在凭证配置完成后人工连通验证。
5. 原有工作台完整回归；变更有运维说明、Evidence、可回滚提交和技术债。

## 执行顺序

规格/ADR → 连接与凭证接口 → SQLite 无密审计 → HTTP/本机回调 → 测试与本地部署已完成；验收见 `harness/evidence/HA-0010/`。等待用户完成官方应用/授权的真实探针转入 HA-0011。
