# HA-0012 百度网盘分享链接官方客户端下载 Skill

状态：completed。用户要求从聊天中读取明确提供的分享链接，并通过本机官方客户端完成下载；同时同步到 Claude。

实施清单：

1. 限定来源为当前用户消息或用户明确引用的消息，且仅允许 `https://pan.baidu.com/s/...`。
2. 通过 stdin 将链接交给固定官方 macOS 客户端；输出只含 SHA-256 摘要，不保存/回显 URL 或 `pwd`。
3. 明确保留用户在客户端登录、提取码确认、保存位置和下载确认；不自动化 GUI 或调用未核验文件 API。
4. 下载后只接受用户明确提供的 `~/Downloads` 常规文件路径，拒绝目录、外部路径和符号链接，不读取内容。
5. 验证 CLI、URL 边界、路径边界和脱敏输出，并同步项目 Skill 到 Claude 的个人 Skill 目录。

非目标：列目录、直接 API 下载、Cookie/验证码处理、浏览器爬取、自动内容解析、文件移动/删除/上传。它们仍受 TD-020 门禁。
