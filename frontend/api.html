Local API · v0.1

服务仅供本机单用户使用。请求模型见 OpenAPI JSON ↗

方法 路径 用途
POST /api/v1/resources?name=data.csv 上传 CSV 原始字节，最多 2 MiB
POST /api/local/tasks 简化任务创建：resource_id、objective、可选 timeout_seconds
POST /api/v1/tasks 严格 Task 契约创建
GET /api/v1/tasks 任务与最新 Run
GET /api/v1/tasks/{id} 不可变任务与全部运行
POST /api/v1/tasks/{id}/runs 新建运行，body: {based_on_run_id, reason}
POST /api/v1/runs/{id}:cancel 幂等取消
GET /api/v1/runs/{id}/events?after=0 JSON 事件游标，每页最多 500 条
GET /api/v1/runs/{id}/artifacts 列出运行产物
GET /api/v1/artifacts/{id}/content?download=true 下载不可变产物
GET /api/v1/engines 引擎可用性
GET /api/v1/health 健康与运行模式

创建一个本地分析

POST /api/local/tasks
Content-Type: application/json
Idempotency-Key: a-unique-request-key

{
  "resource_id": "res_...",
  "objective": "检查数据质量并汇总数值",
  "timeout_seconds": 60
}

Task 与 Run 创建要求 Idempotency-Key；相同键和请求重放响应，不同内容返回 409。仅支持 prj_local / local_analytics@1 / engine_mock_analytics。

目标作为任务记录保存，当前执行固定数值统计；尚未接入真实模型与代码沙箱。
