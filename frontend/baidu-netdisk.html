首次配置

KEYCHAIN · LOCAL ONLY
  1. 在百度网盘开放平台创建应用，登记本机回调地址。
  2. 设置公开的 HARNESS_BAIDUPAN_CLIENT_ID。
  3. 在 macOS Keychain 的 HarnessAgent.BaiduNetdisk 服务下保存账户 oauth-client-secret。
  4. 点击左侧按钮，在百度页面自行登录并授权 basic,netdisk。

Client Secret、access token 和 refresh token 不会进入 SQLite、日志、任务、产物或 Evidence。本版仅实现连接，不开放文件列举、下载或分享链接导入。

打开百度网盘开放平台 ↗

授权边界

授权 state 单次使用、10 分钟过期；回调固定到 127.0.0.1。请不要在飞书、截图、配置文件或终端历史中粘贴 Secret 或 token。
